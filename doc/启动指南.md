# Satori 启动指南

---

## 环境变量

`SATORI_HOME` 指定项目数据存放位置（聊天记录、记忆、数据库、配置等）。

如果不设置，默认存在 `C:\Users\你的用户名\.hanako-dev`（C 盘）。

我们已设为 E 盘（不占 C 盘）：

| 设置方式 | 命令 | 说明 |
|---------|------|------|
| 永久生效 | `setx SATORI_HOME "E:\AI_agent\.hanako-dev"` | 新终端自动加载 |
| 仅当前窗口 | `set SATORI_HOME=E:\AI_agent\.hanako-dev` | 立刻生效 |

## 启动项目

```bash
cd E:\AI_agent\openhanako

# 首次或装新依赖后
npm install

# 启动
npm start
```

### 各步骤说明

`npm start` 会自动执行：

1. `build:preload` — 构建 Electron preload 脚本
2. `build:renderer` — 构建 React 前端（Vite 打包）
3. `build:theme` — 构建主题 CSS
4. `launch.js electron` — 启动 Electron 桌面窗口

### 其他启动方式

```bash
npm run start:dev    # 开发模式
npm run cli          # 命令行模式（不开窗口）
npm run server       # 仅启动后端服务
npm run dev:web      # Web 开发模式
```

## 第一次启动

第一次启动会弹出配置向导，需要：

1. 选择语言
2. 输入你的名字
3. 配置模型提供商（API key + 地址）
4. 选择三个模型：对话模型、小工具模型、大工具模型

配置一次后会自动保存，以后启动不再重复。

## 常见问题

**Q: 启动很慢？**
第一次启动需要下载 Electron 二进制（~150MB）和构建前端。后续启动只走缓存，会快很多。

**Q: Electron 下载卡住？**
设置国内镜像：
```bash
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm start
```

**Q: 改了服务器端代码（TypeScript）但重启后工具/功能没生效？**
Satori 的 Electron 启动后会派生子进程运行服务端。`npm start` 如果旧进程未退出，新启动的 Electron 可能连到旧服务器，导致代码改动不生效。**必须先杀掉所有残留进程再重启：**

```powershell
# 杀掉所有 node 和 electron 进程
Get-Process -Name "node","electron" -ErrorAction SilentlyContinue | Stop-Process -Force

# 重新构建前端 + 启动
npm run build:renderer && npm start
```

如果只改了服务端代码（`core/`、`lib/` 下），不需要 `build:renderer`，直接杀进程后 `npm start` 即可。
`dev:renderer`（Vite 热更新）存在缓存问题，改动后可能不生效。**不要依赖热更新来验证 Desktop 改动**，正确的开发流程：

1. `npm run build:renderer` — 构建生产包到 `dist-renderer/`
2. `npm start` — 启动 Electron（读 `dist-renderer/`，非热更新路径）

这样所有 Desktop 改动都来自构建产物，不会有缓存问题。

**Q: 数据想改放到别的盘？**
```bash
setx SATORI_HOME "D:\你的路径\.hanako-dev"
```
然后重新启动。
