# 参赛用素材 · 目录与使用说明

这个文件夹收录**开发过程中遇到的真实问题与解决过程**，用途有两个：

1. **参赛材料**：作为"工程真实度"的佐证素材——评委最容易被"遇到过什么坑、怎么定位、怎么取舍"打动，而不是功能清单。
2. **面试复习**：每篇都是独立故事，按"一句话版 → 现象 → 原因 → 解决 → 面试怎么讲"组织，面试前把几篇的"一句话版"和"可能被追问"过一遍即可。

## 与 doc/iterations 的关系

- `doc/iterations/`：**给工程看的**，含代码、函数名、文件行号、测试细节。
- `doc/参赛用素材/`：**给人看的**，只有叙事与技术名词，不含代码。

同一件事两边各有一份：先读这里的叙事版建立理解，需要细节再去 iterations 查证。

## 面试使用建议

- 每篇开头的「一句话版」是 30 秒电梯版；「展开讲」是 2 分钟版。
- 结尾的「可能被追问」是预判的深挖问题，务必过一遍——追问答不上比不会讲更减分。
- 三个故事共享同一条主线：**在一个有既有契约的系统上做新功能，先弄清平台自己是怎么做的，再决定怎么做**。这条主线本身就可以作为设计哲学来讲。
