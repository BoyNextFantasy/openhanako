# 剥离指南 — 从 OpenHanako 到纯 CLI Coding Agent

## 可以直接删除的模块

| 模块 | 说明 | 改动量 |
|------|------|--------|
| `desktop/` | Electron 桌面 UI（1608 文件） | 删目录，修 2 处 import |
| `plugins/` | 内置插件（image-gen, mcp, office, beautify, media） | 删目录，修 1 处 import |
| `packages/` | 插件 SDK（plugin-sdk, plugin-runtime, plugin-protocol, plugin-components） | 直接删目录 |
| `tests/` | 测试文件 | 直接删目录 |
| `scripts/` | 构建/打包/签名脚本 | 直接删目录 |
| `lib/bridge/` | 多平台桥接（Telegram/飞书/QQ/微信） | 删目录，修 1 处引用 |
| `lib/compat/` | 版本兼容性检查 | 删目录，修 1 处引用 |
| `lib/diary/` | Agent 写日记系统 | 删目录，检查引用 |
| `lib/experiments/` | 实验开关（proactive subagent 等） | 删目录，修 import |
| `lib/character-cards/` | 角色卡系统 | 直接删 |
| `lib/skill-bundles/` | 技能包导出 | 直接删 |
| `lib/extensions/` | Pi 兼容扩展加载 | 如果不用 Pi 扩展体系就删 |
| `lib/channels/` | 频道系统（多 Agent 群聊） | 如果不需要多 Agent 协作 |
| `lib/conversations/` | 对话管理 | 检查引用 |
| `lib/workflow/` | 工作流编排 | 检查引用 |

## 建议保留的模块（coding agent 需要）

| 模块 | 理由 |
|------|------|
| `lib/memory/` | 记忆系统（事实存储 + 滚动摘要 + 长期记忆） |
| `lib/skills/` | 自学习机制（SKILL.md 安装/编写） |
| `lib/sandbox/` | 代码执行安全隔离（PathGuard + OS 沙盒） |
| `lib/tools/` | 工具集（选择性删除 card-guide, show-card 等） |
| `lib/shell/` | 终端集成 |
| `lib/terminal/` | 终端 session 管理 |
| `lib/fresh-compact/` | 会话压缩（省 token） |
| `lib/providers/` | LLM 提供商列表（不删就没模型用） |
| `lib/pi-sdk/` | Pi 适配层（核心，删不了） |
| `lib/llm/` | LLM 用量统计 |
| `lib/session-files/` | 会话文件管理 |
| `lib/resource-io/` | 资源 I/O（sandbox 需要） |
| `lib/approval-gateway.ts` | 审批门（子 agent 管线需要） |
| `lib/deferred-result*` | 子 agent 异步结果传递 |
| `lib/checkpoint-store.ts` | 文件修改快照（coding agent 需要） |
| `lib/task-registry.ts` | 后台任务管理 |
| `lib/notifications/` | 通知系统 |
| `lib/i18n.ts` | 国际化（保留，只有 1 文件） |
| `lib/debug-log.ts` | 日志（保留） |

## core/ 里可以删的模块

| 模块 | 说明 |
|------|------|
| `core/computer-use/` | 电脑操作（鼠标键盘），纯 coding agent 不需要 |
| `core/media/` | 媒体处理（纯文本 coding agent 不需要） |
| `core/speech-recognition/` | 语音识别 |
| `core/session-manifest/` | session 清单索引（可选，看你需要树结构 session 不） |
| `core/provider-compat/` | 提供商兼容层（建议保留，让模型兼容性好） |

## core/ 里必须保留的

| 文件 | 理由 |
|------|------|
| `core/engine.ts` | 引擎门面 |
| `core/agent.ts` | Agent 类（identity + 工具 + system prompt） |
| `core/agent-manager.ts` | Agent 生命周期管理 |
| `core/session-coordinator.ts` | Session 创建/切换/executeIsolated |
| `core/config-coordinator.ts` | 配置管理 |
| `core/model-manager.ts` | 模型管理 |
| `core/preferences-manager.ts` | 偏好设置 |
| `core/skill-manager.ts` | 技能管理 |
| `core/plugin-manager.ts` | 插件管理（保留入口） |
| `core/llm-client.ts` | 直接 LLM 调用 |
| `core/llm-utils.ts` | LLM 工具函数 |
| `core/slash-command-registry.ts` + `slash-commands/` | 斜杠命令系统 |
| `core/message-sanitizer.ts` | 消息清洗 |
| `core/session-compactor.ts` | 会话压缩 |
| `core/vision-bridge.ts` | 图片支持（可选，coding 可能需要） |
| `core/tool-availability.ts` | 工具可用性控制 |

## hub/ — 保留

9 个文件，深度耦合，切不掉：
- `event-bus.ts` — 事件总线
- `scheduler.ts` — 心跳 + Cron
- `channel-router.ts` — 频道消息路由
- `dm-router.ts` — Agent 私信路由
- `guest-handler.ts` — 访客处理
- `agent-executor.ts` — Agent 后台执行器
- `agent-phone.ts` — Agent 电话活动

## server/routes/ 裁剪

保留（CLI 必需）：
- `chat.ts` — WebSocket 会话（核心）
- `sessions.ts` — 会话管理
- `agents.ts` — Agent 管理
- `config.ts` — 配置
- `models.ts` — 模型
- `providers.ts` — 提供商
- `auth.ts` / `ws-auth.ts` — 认证
- `fs.ts` — 文件系统
- `upload.ts` — 文件上传

删除（web UI 专用）：
- `desk.ts`, `bridge.ts`, `plugins.ts`, `mobile-*.ts`
- `media.ts`, `speech-recognition.ts`
- `computer-use.ts`
- `channels.ts`, `dm.ts`
- `diary.ts`, `experiments.ts`
- `character-cards.ts`, `checkpoint.ts`
- `commands.ts`
- `usage.ts`, `resource-io.ts`
- `plugin-dev.ts`, `plugin-iframe-ticket.ts`, `plugin-asset-session.ts`, `plugin-surface-session.ts`
- `settings-snapshot.ts`, `studio-workspace.ts`
- `provider-credentials.ts`（如果不需要）

## server/http/ — 保留

HTTP 基础设施（middleware、CORS、security 等），core 依赖它。

## server/ 根文件 — 保留

- `index.ts` — 主入口（CLI server 模式）
- `security-boot.ts` — 安全启动
- `ws-chat.ts` — WebSocket 聊天处理（核心）

## 执行步骤

```bash
# 1. 备份
cd E:\AI_agent
Copy-Item openhanako my-coding-agent -Recurse
cd my-coding-agent

# 2. 删大目录
Remove-Item -Recurse -Force desktop/
Remove-Item -Recurse -Force plugins/
Remove-Item -Recurse -Force packages/
Remove-Item -Recurse -Force tests/
Remove-Item -Recurse -Force scripts/

# 3. 删 lib 子模块
Remove-Item -Recurse -Force lib/bridge/
Remove-Item -Recurse -Force lib/compat/
Remove-Item -Recurse -Force lib/diary/
Remove-Item -Recurse -Force lib/character-cards/
Remove-Item -Recurse -Force lib/skill-bundles/
Remove-Item -Recurse -Force lib/workflow/
Remove-Item -Recurse -Force lib/conversations/
Remove-Item -Recurse -Force lib/channels/
Remove-Item -Recurse -Force lib/extensions/
Remove-Item -Recurse -Force lib/experiments/

# 4. 删 core 子模块
Remove-Item -Recurse -Force core/computer-use/
Remove-Item -Recurse -Force core/media/
Remove-Item -Recurse -Force core/speech-recognition/

# 5. 删 server 路由
Remove-Item -Recurse -Force server/routes/desk.ts
Remove-Item -Recurse -Force server/routes/bridge.ts
# ... 其他路由按需删除

# 6. 改代码修 import
# core/migrations.ts → 删 bridge 引用
# core/agent.ts → 删 compat/experiments 引用
# core/media/universal-media-manager.ts → 改 plugins 为 lazy import
# server/routes/plugins.ts → 改 desktop 主题引用
# lib/tools/update-settings-tool.ts → 改 desktop 主题引用

# 7. 验证
npm run typecheck
npm run cli
```
