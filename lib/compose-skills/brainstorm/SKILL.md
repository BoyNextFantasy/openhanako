# Compose Brainstorm

Use this when a request is broad, ambiguous, or has multiple viable approaches.

Identify the user's goal, constraints, out-of-scope items, risks, and a small set of options. Ask concise questions only when the missing information changes the implementation choice. End with a recommended direction and what would make it successful.
