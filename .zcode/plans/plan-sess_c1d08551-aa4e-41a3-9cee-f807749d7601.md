### 2. 为什么做这个项目？
- 以做代学：五个核心主题，读文章只能知道概念，做一遍才知道坑在哪（举例：阻塞式工具会让轮次死亡、提示词被长对话稀释）——都是踩过才写进机制的
- 底座来自开源 Pi SDK，精力花在策略层
- 以赛促练：作品赛驱动打磨成完整体系

### 3. 技术选型是什么样的？（每项一句"为什么"，落点都是本地桌面单用户场景）
Pi SDK（运行时开箱即用，专注策略层，详见 Q16）/ TypeScript+Node（类型安全撑工程化，前后端同语言）/ Electron+React（同类多是 CLI，要桌面 GUI 可视化）/ SQLite+FTS5（单文件零部署，记忆不需要独立数据库服务）/ Vitest（测试体系载体）

### 4. 相比同类产品有什么优势？（对标 Claude Code / Codex / Cursor）
三点差异化：①安全治理是主线（5 模式×5 层防线+全量留痕，同类普遍只有确认/白名单两级）②跨会话记忆内置体系（三级摘要→元事实→编译注入）③桌面端可视化+本地化（任务树/计划卡/用量看得见，数据不出本机）。诚实边界：生态广度不如商业产品，定位是把 Agent 工程关键问题做深的参赛作品。
