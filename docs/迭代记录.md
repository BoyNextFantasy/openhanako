## 2026-06-30：剥离模块 — 删除 plugins/jimeng-cli

- **分支**：`iter/brand-satori`（沿用同一分支）
- **目标**：删除即梦 CLI 插件，验证剥离流程

### 这是什么
即梦 AI 画图插件。AI 通过调用系统命令行 `dreamina` 来生成图片和视频。作为插件通过 bus 事件向 `image-gen` 注册 adapter，与核心引擎无直接 import 耦合。

### 用户能感觉到什么变化
- 删之前：AI 有 `generate_image` / `generate_video` 等画图工具可用
- 删之后：AI 不再提供即梦（Dreamina）相关的图片/视频生成能力

### 改动
- 删除 `plugins/jimeng-cli/` 目录（4 文件）
- 删除专用测试文件 `tests/jimeng-cli-adapter.test.ts`、`tests/jimeng-cli-provider.test.ts`
- 清理 7 个文件中的 jimeng-cli 引用（测试数据替换为 test-* 泛型）
- 删除桌面端 `MediaProviderDetail.schema.test.tsx`（已无测试用例）

### 验证
- **代码残留**：`rg 'jimeng' --glob '!node_modules'` → 0 匹配 ✅
- **全量测试**：`npm test` — 22 failures（同预存，未引入新失败），6923/6955 passed
- **用户亲手测**：启动 `npm run cli`，查看工具列表，不应再出现 jimeng 相关工具
