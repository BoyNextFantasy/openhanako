## 2026-07-02：Question 工具端到端修复 — Modal 弹窗 + Hooks 顺序 + Abort 预检查

- **分支**：`iter/mode-switching`
- **目标**：修复 Question 工具端到端链路问题（Modal 不渲染、新对话弹错）

### 发现与修复

**问题 1：QuestionModal sessionPath key 不匹配**
- `setPendingQuestion` 用 `sessionScopedKey(s, path)`（可能返回 sessionId）存
- `QuestionModal` 直接用 `currentSessionPath`（原始路径）查
- key 不一致 → `pendingByPath[currentSessionPath]` 永远是 `undefined` → Modal 不渲染
- **修复**：改用 `sessionScopedValue()` 先查 sessionId 再 fallback 原始路径

**问题 2：React Hooks 顺序不一致导致 ErrorBoundary 弹 "Something went wrong"**
- `if (!currentSessionPath) return null` 在第 4 个 `useStore` 调用之前
- 当 `currentSessionPath` 在 `null ↔ 有效路径` 间切换时（开新对话瞬态），hooks 数量从 4 变为 3
- React 检测到变化 → 抛错 → ErrorBoundary → "Something went wrong / Retry"
- Click Retry 后 store 稳定，hooks 数一致，不再报错
- **修复**：将第 4 个 `useStore` 移到 `return` 之前，始终保持 4 个 hooks

**问题 3：`signal?.aborted` 预检查可能误拒**
- 当 Signal 已废弃时立刻 reject，不发射 event
- **修复**：移除预检查，只监听未来 abort 事件

**问题 4：Desktop 构建被 EPERM 阻塞**
- `build:renderer` 因 `dist-renderer/assets` 被锁而失败
- 改的 `.tsx` 源码从未编译进运行版本
- **修复**：手动删除 `dist-renderer` 后重新构建
